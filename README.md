# Power BI – Product Sales Analysis

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze product sales performance and provide insights into revenue, units sold, customer ratings, pricing, and taxes.

## 📂 Repository Contents
- `Top_Selling_Products.xlsx` – Original dataset.
- `Product_Sales_Analysis.pbix` – Power BI report and interactive dashboard.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key Metrics (KPIs)
- Total Units Sold
- Total Revenue
- Average Rating
- Total Tax
- Average Price

## 📈 Dashboard Visualizations
- Revenue by Product Name
- Units Sold by Product Name
- Revenue by Category
- Units Sold by Category

## 🎯 Project Objective
To explore product and category performance, identify top-selling products, and understand revenue distribution through interactive data visualization.
